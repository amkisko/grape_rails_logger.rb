## Decisions

- Relock grape to 3.3.5 in Gemfile.lock and appraisal lockfiles.
- Keep the published gem at 1.2.1. Public endpoint.options Hash access still works on grape 3.3.5, so no runtime code change and no CHANGELOG Unreleased bullet.
- Prove the contract with live Grape routes: log :action from POST /users and GET /users/:id in the unit suite, and from GET /railtie-health in Railtie isolation.
- Keep json on 2.21.2.

## Effects

- Root Gemfile.lock moved grape from 2.4.0 to 3.3.5. Appraisal lockfiles moved from 3.3.4 to 3.3.5.
- grape 3.3.5 dropped mustermann-grape for mustermann >= 4.0 and added dry-configurable. Those pins followed in the test graph.
- Hash options[:method] and options[:path] still feed extract_action.
